## Summary

This RFC defines the bounded `workspace/symbol` surface that closes IDE-2311.
`ling.lsp.workspace-symbol/0.1` searches resolver-owned user definitions from
one complete immutable workspace snapshot, reuses an exact snapshot-keyed
session cache, preserves module and workspace URI context, projects original
UTF-8 spans through the negotiated position encoding, caps results
deterministically, and checks cooperative cancellation before publication.

本 RFC 定义关闭 IDE-2311 的有界 `workspace/symbol` 接口。该接口从完整不可变工作区
快照中的 resolver 用户定义执行搜索，复用按精确快照键控的会话缓存，保留模块与工作区
URI 上下文，通过协商的位置编码投影原始 UTF-8 跨度，确定性限制结果，并在发布前检查
协作式取消。

## Normative changes

### 1. Provider and discovery

Every successful initialize response MUST advertise:

```json
"workspaceSymbolProvider": {
  "resolveProvider": false,
  "workDoneProgress": false
}
```

It MUST also advertise this exact Experimental member:

```json
"lingWorkspaceSymbols": {
  "cache": "complete-snapshot",
  "cancellation": "cooperative-host-token",
  "matching": "exact-or-prefix-case-sensitive",
  "maxQueryBytes": 256,
  "maxSymbols": 256,
  "scope": "tracked-workspace-sources",
  "version": "ling.lsp.workspace-symbol/0.1"
}
```

The standard provider does not imply resolve, partial results, work-done
progress, or `$/cancelRequest`. Changing any discovery field requires a new
marker and migration evidence.

### 2. Request and lifecycle

The extension adds exactly one request:

| Method | Kind | Ready result |
| --- | --- | --- |
| `workspace/symbol` | request | zero to 256 `SymbolInformation` items |

`params` MUST be an object with required string `query`. Ordinary unknown
members, including standard progress tokens, are ignored. The query MUST be at
most 256 UTF-8 bytes and MUST NOT contain NUL. Invalid shape or value returns
`-32602`. A notification performs no work and emits no response. RFC-0004
lifecycle failures retain their existing codes and bilingual messages.

### 3. Snapshot and workspace scope

The handler MUST capture one complete `RequestSnapshot` before analysis. Its
workspace is exactly the tracked documents whose RFC-0023 identity is
non-temporary and writable. This includes visible open overlays and tracked
closed disk snapshots already supplied by the host. It excludes dependency
URIs, untitled documents, and any source absent from the snapshot; the handler
MUST NOT read the filesystem or discover a project root.

The URI authority supplies workspace-package context. Each result's
`containerName` supplies the resolver module name. Version 0.1 defines no
additional package field and exposes no host path.

The handler MUST compile the complete non-temporary captured workspace through
the existing `CompilerDb` and consume `ResolvedDefinitionIndex`. It MUST NOT
parse source independently, derive symbols from diagnostics or message text,
or expose resolver/Definition/Semantic IDs.

### 4. Snapshot-keyed incremental index

The server MAY retain exactly one immutable workspace-symbol plan. The cache
key MUST be the complete `RequestSnapshot`, including lifecycle state,
position encoding, workspace revision, ordered document identities, origins,
versions and exact bytes, and ordered project inputs. Equal keys MUST reuse an
equal plan. Any difference MUST rebuild the complete plan before publication.

The cache is session-local and disposable. Failed, stale, oversized, or
cancelled construction MUST NOT replace the last complete plan. No cache byte,
hit/miss, allocation, timing, or persistence behavior is public semantics.

### 5. Symbols, matching, and ordering

The source domain is exactly the existing resolver-owned user-definition
inventory after filtering to sources in §3. Builtins and Prelude entries are
already excluded. Version 0.1 maps resolver kinds as follows:

| Resolver kind | LSP `SymbolKind` |
| --- | ---: |
| Value | Variable `13` |
| Type | Class `5` |
| Constructor | EnumMember `22` |
| TraitMember | Method `6` |
| ImplementationMember | Method `6` |

An empty query matches every item. Otherwise, an item matches when its exact
source name equals the query or starts with the query as UTF-8/Unicode scalar
text. Matching is case-sensitive and byte-preserving. It performs no NFC/NFD
conversion, confusable folding, locale transform, tokenization, fuzzy search,
or module-name search.

Matches sort by:

1. exact-name match before prefix-only match;
2. source name by Unicode scalar/UTF-8 lexicographic order;
3. module name;
4. URI;
5. original start byte, end byte, resolver kind, and internal definition
   identity as a final internal-only tie-breaker.

The internal identity MUST NOT be serialized. The first 256 sorted matches are
returned; later matches are deterministically omitted. Repeated equal
snapshots and queries MUST return structurally equal results independent of
document insertion, map, allocation, thread, clock, environment, filesystem,
or cache-hit order.

### 6. Result and positions

Each result is a standard `SymbolInformation` object with exactly:

```json
{
  "containerName": "Support",
  "kind": 13,
  "location": {
    "range": {
      "end": {"character": 10, "line": 2},
      "start": {"character": 4, "line": 2}
    },
    "uri": "ling://workspace/src/Support.ling"
  },
  "name": "answer"
}
```

`name` is the resolver's exact source spelling and `containerName` is always
the exact resolver module name. `location.uri` is the exact captured workspace
URI. `range` projects the resolver-owned original UTF-8 span through DEC-0029
in the initialize-negotiated UTF-8, UTF-16, or UTF-32 encoding. BOM and CRLF
remain governed by the source map. No tags, deprecated flag, score, package
path, version, identity, `data`, or extension field is emitted.

### 7. Cancellation, freshness, bounds, and failures

The workspace-symbol query MUST accept the existing DEC-0031 cooperative
`CancellationToken` from its in-process owner. It MUST check before compiler
work, during plan construction and result filtering, and immediately before
publication. Cancellation discards partial work, leaves the prior cache and
server state unchanged, and returns standard RequestCancelled `-32800` with
`工作区符号查询已取消 / workspace symbol query cancelled`.

`handle_json` uses a fresh active token. The in-process
`handle_json_with_cancellation` entry point lets an embedding owner cancel the
same query from another thread. The synchronous RFC-0004 stdio loop cannot
observe a later wire notification while it is executing a request, so this RFC
does not claim `$/cancelRequest`; that transport remains LSP-2502 work.

The complete snapshot MUST be recaptured before success. A difference returns
RequestFailed `-32803`. Compiler, source, span, position, index, or freshness
failure and a success response above the RFC-0004 1 MiB bound also return
`-32803`, with `工作区符号不可用 / workspace symbols unavailable`. Failures
emit no partial result, allocate no Ling diagnostic, and mutate no document,
version, VFS, project, diagnostic publication, source, disk, or runtime state.

## Conformance plan

- Verify exact provider/discovery, lifecycle, notification silence, params,
  query byte/NUL bounds, empty query, fixed failures, and response bound.
- Cover exact and prefix matching, no case/NFC/fuzzy/module matching, kind
  mapping, module containers, exact workspace URIs, dependency and temporary
  exclusion, and compiler failure.
- Cover Unicode, Chinese, decomposed/NFC distinctions, emoji/combining prefixes,
  BOM, CRLF, UTF-8/16/32 positions, duplicate names, source insertion order,
  exact-before-prefix order, deterministic 256-result truncation, and repeat
  equality.
- Verify equal-snapshot cache reuse, revision/input/document invalidation,
  failed-build cache isolation, stale-snapshot rejection, and no persistence.
- Verify pre-cancel and cooperatively cancelled construction/filtering return
  `-32800` without partial publication or cache mutation; retain the explicit
  absence of a stdio `$/cancelRequest` claim.
- Add exact protocol fixtures and run locked offline workspace tests, strict
  Clippy, CI, governance, LSP, support, status, RC0, traceability, formatting,
  diff, and execution-plan checksum gates.

## Compatibility impact

- **Protocol:** adds Preview `ling.lsp.workspace-symbol/0.1` with no predecessor.
- **Compiler/query:** consumes the existing resolved-definition inventory and
  adds one disposable complete-snapshot LSP presentation cache; compiler query
  identity and semantics do not change.
- **Cancellation:** composes DEC-0031 into this one bounded query and adds an
  in-process owner entry point; no wire cancellation protocol is claimed.
- **Diagnostics/schema/identity:** no `L-*` code, JSON schema file, Semantic ID,
  DefinitionId, or canonical-byte change.
- **Language/runtime/data:** no Ling syntax/semantics, Typed Core evaluation,
  interpreter, runtime, bytecode, VM, ABI, package format, filesystem/network,
  or Unicode 17.0.0 table change.
- **Migration:** no predecessor; incompatible matching, scope, kind, field,
  ordering, limit, cache-key, cancellation, or failure changes require a new
  marker and migration evidence.

## Unresolved alternatives

Dependency/generated/builtin/Prelude search, explicit package fields,
top-level-only filtering, fuzzy/case-folded/normalized/module search, scores,
client-configurable limits, incomplete metadata, resolve, partial results,
work-done progress, stdio `$/cancelRequest`, concurrent scheduling, persistent
indexes, filesystem discovery/watchers, Semantic IDs, documentation/types,
Stable compatibility, and general Semantic Transaction behavior remain future
work.
